# Лабораторная №9 — Клиентский JavaScript

## Запуск
Распакуйте архив и откройте index.html в современном браузере. Сервер, npm и установка пакетов не нужны. Все файлы должны оставаться в одной папке.

## Состав
- index.html — структура страницы, без заранее созданных карточек.
- styles.css — оформление и адаптация под узкий экран.
- models.js — классы из предоставленной лабораторной №8, без консольной демонстрации. Код классов сохранён.
- app.js — данные и создание интерфейса через DOM.

## Реализация
createTrackCard(track) возвращает article с данными композиции и data-track-id. В исходном классе Track нет обложки, поэтому все исходные композиции используют заглушку. Функция также поддерживает необязательное поле coverUrl и заменяет не загрузившуюся картинку заглушкой.

renderCatalog(tracks) очищает контейнер через replaceChildren, собирает карточки в DocumentFragment и обновляет количество. При пустом массиве показывает сообщение.

renderPlaylist(playlist) показывает номер, название, исполнителя, продолжительность и кнопку удаления. Счётчик и общая длительность берутся из класса Playlist. В плейлисте три композиции общей длительностью 11:09.

Текст задаётся через textContent. DOM-функции только читают объекты, массив каталога и содержимое плейлиста не изменяют. Идентификаторы записываются через dataset.

По условию задания кнопки и поля управления могут не реагировать на пользователя. Они намеренно отключены через disabled. Реального воспроизведения нет, аудиофайлы в комплект не входят. Это работа по отображению данных через DOM.

## Проверка в консоли браузера
Откройте инструменты разработчика (F12), вкладку Console.

```js
// Повторная отрисовка: количество карточек должно остаться равным 6.
renderCatalog(tracks);
renderCatalog(tracks);
document.querySelectorAll('.track-card').length;

// Пустой каталог и восстановление.
renderCatalog([]);
renderCatalog(tracks);

// Пустой плейлист и восстановление.
renderPlaylist(new Playlist('Пустой'));
renderPlaylist(playlist);

// В исходных данных остались 6 композиций и 3 элемента плейлиста.
tracks.length;
playlist.itemsCount;
```

Last Train демонстрирует отсутствие альбома. У всех композиций есть заглушка обложки.

## Контрольные вопросы
1. **DOM** — объектное представление документа в виде дерева узлов; JavaScript использует его для чтения и изменения страницы.
2. **Преобразование HTML:** браузер разбирает разметку, создаёт узлы и связывает их в дерево согласно правилам HTML. Некорректная разметка может быть исправлена парсером.
3. **document** — объект текущего документа, точка доступа к его узлам и методам создания и поиска.
4. **window и document:** window представляет окно/контекст браузера и содержит document, а также таймеры, location и другие браузерные API.
5. **Узел** — объект дерева документа: например, элемент, текст или комментарий.
6. **Типы узлов:** Document, Element, Text, Comment, DocumentType, DocumentFragment.
7. **Элемент и текст:** элемент имеет тег и атрибуты, текстовый узел содержит текст без собственного тега.
8. **Поиск по ID:** document.getElementById('catalog').
9. **querySelector / querySelectorAll:** поиск элементов по CSS-селектору.
10. **Разница:** querySelector возвращает первый элемент или null, querySelectorAll — статический NodeList всех совпадений.
11. **Селекторы:** #id, .class, article, [data-track-id], .catalog > article и другие корректные CSS-селекторы. Некорректный селектор вызывает исключение.
12. **createElement:** создаёт новый DOM-элемент по имени тега.
13. **Появление на странице:** после вставки в подключённое дерево документа, например через append. Сам createElement ничего на страницу не вставляет.
14. **Изменение текста:** element.textContent = 'Текст'. Это заменяет дочернее содержимое текстовым узлом, не интерпретируя HTML.
15. **Атрибут:** element.setAttribute('title', 'Подсказка'); удалить — removeAttribute.
16. **Свойства и атрибуты:** атрибуты содержат строковые значения разметки, свойства — значения JS и текущее состояние. Например, input.value может отличаться от исходного атрибута value; button.disabled — логическое свойство.
17. **data-*:** пользовательские данные элемента, например идентификатор связанного объекта.
18. **data-track-id:** element.dataset.trackId.
19. **Преобразование имени:** data-track-id превращается в trackId, дефис перед строчной ASCII-буквой убирается, буква становится заглавной.
20. **Тип dataset:** строки. Для сравнения с числовым id можно использовать Number(element.dataset.trackId).
21. **className:** чтение или замена всей строки классов элемента.
22. **classList:** управление отдельными CSS-классами.
23. **Методы classList:** add добавляет, remove удаляет, toggle переключает наличие класса; вторым аргументом toggle можно принудительно задать состояние.
24. **Наличие класса:** element.classList.contains('active').
25. **append / prepend:** добавляют узлы или строки в конец / начало дочернего содержимого.
26. **before / after / remove:** вставляют соседей перед / после узла или удаляют сам узел.
27. **DocumentFragment:** отдельный контейнер для подготовки группы узлов. При вставке фрагмента его дети переносятся в целевой контейнер, фрагмент опустошается.
28. **Скрытие и удаление:** при скрытии через hidden или CSS узел остаётся в DOM; remove отсоединяет его от дерева, но объект может сохраняться, пока на него есть ссылки.
29. **Динамический интерфейс:** интерфейс, содержимое или состояние которого изменяется программно, например после получения данных или действий пользователя.
